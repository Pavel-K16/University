Формулы расчёта декремента

Логарифмический декремент за период (пики через один):

δn = ln An An+2

Средний декремент по интервалу:

δ = 1N Σ n=1 N δn

Связь с процентным уменьшением амплитуды за один пик-период:

decay(%) = (1- e-δ ) ·100%

Амплитуда пика:

An = | x(tn) - xeq |

Где tn — момент времени, в который достигается n-й амплитудный пик (локальный максимум амплитуды).

Шпаргалка (декремент)

Амплитуда n-го пика:

An = | x(tn) - xeq |

Декремент за период (пики через один):

δn = ln An An+2

Средний декремент по интервалу:

δ = 1N Σ n=1 N δn

Уменьшение амплитуды за один пик-период:

decay(%) = (1- e-δ ) ·100%

Связь с коэффициентом затухания (underdamped):

ζ = δ 4π2+δ2 δ = 2πζ 1-ζ2

Здесь tn — момент времени, в который достигается n-й амплитудный пик.
