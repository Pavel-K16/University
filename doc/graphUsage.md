# Графовая система для решения задач о колебаниях

## Обзор

Новая графовая система позволяет описывать системы тел и их связи явным образом, следуя теории графов.

## Основные структуры

### Node (Узел)
```go
type Node struct {
    ID        int     // уникальный идентификатор
    Mass      float64 // масса
    Position  float64 // текущее положение
    Velocity  float64 // текущая скорость
    K         float64 // собственная жёсткость (пружина относительно земли)
    D         float64 // собственное демпфирование (демпфер относительно земли)
    Edges     []Edge  // список связей с другими узлами
    IsFixed   bool    // флаг жёсткого закрепления
}
```

### Edge (Ребро)
```go
type Edge struct {
    TargetID int     // ID узла, с которым связь
    K        float64 // коэффициент жёсткости k_ij
    D        float64 // коэффициент демпфирования d_ij
    Rest     float64 // длина покоя
}
```

## Пример использования

### Простая задача: одно тело на пружине

```go
graph := config.NewGraph()

// Создаём закреплённый узел (земля)
ground := config.NewFixedNode(0, 0.0)
graph.AddNode(ground)

// Создаём подвижное тело
body := config.NewMovableNode(1, 1.0, 1.0, 0.0, 1.0, 0.1)
// 1.0 - масса
// 1.0 - начальное положение
// 0.0 - начальная скорость
// 1.0 - жёсткость пружины
// 0.1 - демпфирование
graph.AddNode(body)

// Связь через пружину и демпфер
graph.AddEdge(0, 1, 1.0, 0.1, 0.0)
// От узла 0 к узлу 1
// k=1.0, d=0.1, rest=0.0

// Создаём решатель
solver := equationsolver.NewGraphSolver(graph, dt)

// Решаем
for t := 0.0; t <= T; t += dt {
    solver.Step(t)
}
```

### Задача о метрономах

```go
graph := config.NewGraph()

// 1. Неподвижная платформа
fixedPlatform := config.NewFixedNode(0, 0.0)
graph.AddNode(fixedPlatform)

// 2. Подвижная платформа
mobilePlatform := config.NewMovableNode(1, 1.0, 4.0, 0.0, 0.0, 0.0)
graph.AddNode(mobilePlatform)

// 3. Метроном 1
metronome1 := config.NewMovableNode(2, 1.0, 2.0, 0.0, 1.0, 1.0)
graph.AddNode(metronome1)

// 4. Метроном 2
metronome2 := config.NewMovableNode(3, 1.0, 3.0, 0.0, 1.0, 0.0)
graph.AddNode(metronome2)

// Связи
graph.AddEdge(0, 1, 1.0, 0.0, 0.0) // платформа ↔ неподвижная основа
graph.AddEdge(2, 3, 1.0, 0.0, 0.0) // метроном 1 ↔ метроном 2

// Создаём решатель
solver := equationsolver.NewGraphSolver(graph, 0.01)

// Решаем
for t := 0.0; t <= 100.0; t += 0.01 {
    solver.Step(t)
    // Сохраняем результаты
}
```

## Как работает система

1. **Узел хранит свои связи** в поле `Edges[]`
2. **При расчёте силы** на узел:
   - Сначала учитываются **собственные силы** узла (K, D относительно земли)
   - Затем проходит по **всем рёбрам** и собирает параметры связанных узлов
   - Вычисляет силы от пружин и демпферов

3. **Для закреплённых узлов** (IsFixed=true):
   - Позиция и скорость не меняются
   - Их можно использовать как "землю" или точки крепления

4. **Связи могут быть любыми**:
   - Только пружина: `AddEdge(i, j, k=1.0, d=0.0)`
   - Только демпфер: `AddEdge(i, j, k=0.0, d=1.0)`
   - И то, и другое: `AddEdge(i, j, k=1.0, d=1.0)`

## Преимущества новой системы

✅ **Явная структура графа** - видны узлы и рёбра
✅ **Каждый узел знает свои связи** - не нужно искать матрицы связей
✅ **Удобное добавление узлов** - простое API
✅ **Поддержка жёстко закреплённых узлов** - флаг IsFixed
✅ **Гибкость связей** - можно задать любую комбинацию пружины/демпфера

## Математика

Для узла `i` чистая сила вычисляется как:

```
F_i = F_ground + Σ F_edges
```

где:
```
F_ground = -K_i * x_i - D_i * v_i
```

```
F_edge = -k_ij * (x_i - x_j - rest_ij) - d_ij * (v_i - v_j)
```

Затем применяется `F = ma`:
```
a_i = F_i / m_i
```

Интегрирование выполняется методом Рунге-Кутты 4-го порядка.
