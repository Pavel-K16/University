# Рекомендуемые параметры для синхронизации метрономов

На основе анализа статей о синхронизации осцилляторов со связью Гюйгенса.

## Ключевые принципы из статей

### Из статьи Pena-Ramirez et al. (2012) - Связь Гюйгенса:

1. **Критический параметр: отношение масс μ = m_oscillator / m_platform**
   - **μ большое (лёгкая платформа)** → синхронизация **в фазе**
   - **μ малое (тяжёлая платформа)** → синхронизация **в противофазе**
   - **μ → 0 (очень тяжёлая платформа)** → отсутствие связи

2. **Экспериментальные значения из статьи:**
   - Осцилляторы: m = 0.210 кг, κ = 37.108 Н/м, β = 2.1378 Н·с/м
   - Лёгкая платформа (синхронизация в фазе): m₃ = 4.1 кг → μ ≈ 0.051
   - Тяжёлая платформа (синхронизация в противофазе): m₃ = 8.818 кг → μ ≈ 0.024

3. **Частоты:**
   - При синхронизации в противофазе: частота ≈ собственная частота осцилляторов
   - При синхронизации в фазе: частота ≈ собственная частота платформы

### Из статьи Woafo-Kraenkel (2002):

1. **Сила связи K** должна быть в диапазоне (0, 1) для стабильности
2. **K > 1** приводит к нестабильности (неограниченный рост)
3. **Демпфирование** важно для времени синхронизации

## Рекомендуемые параметры для вашей системы

### Вариант 1: Синхронизация В ФАЗЕ (лёгкая платформа)

**Метроном 1 (узел 1):**
```go
metronome1 := config.NewMovableNode(1, 
    0.210,  // масса [кг] - как в статье
    0.001,  // начальное положение [м]
    0.0,    // начальная скорость [м/с]
    0.0,    // собственная жёсткость K
    0.0     // собственное демпфирование D
)
```

**Метроном 2 (узел 3):**
```go
metronome3 := config.NewMovableNode(3,
    0.210,  // масса [кг] - идентична метроному 1
    0.0,    // начальное положение [м] - можно сделать небольшим смещением
    0.0,    // начальная скорость [м/с]
    0.0,    // собственная жёсткость K
    0.0     // собственное демпфирование D
)
```

**Подвижная платформа (узел 2):**
```go
metronome2 := config.NewMovableNode(2,
    4.1,    // масса [кг] - ЛЁГКАЯ платформа для синхронизации в фазе
    0.0,    // начальное положение [м]
    0.0,    // начальная скорость [м/с]
    0.0,    // собственная жёсткость K
    0.0     // собственное демпфирование D
)
```

**Связи:**
```go
// Связь метроном 1 с платформой
graph.AddEdge(1, 2, 
    37.108,  // k [Н/м] - жёсткость пружины
    2.1378,  // d [Н·с/м] - демпфирование (из статьи)
    0.0      // rest - длина покоя
)

// Связь метроном 2 с платформой
graph.AddEdge(3, 2,
    37.108,  // k [Н/м] - идентичная жёсткость
    2.1378,  // d [Н·с/м] - идентичное демпфирование
    0.0      // rest
)

// Связь платформы с неподвижной основой
graph.AddEdge(2, 0,
    388.71,  // k [Н/м] - жёсткость связи с основой
    3.2656,  // d [Н·с/м] - демпфирование (из статьи)
    0.0      // rest
)
```

**Ожидаемое поведение:**
- μ = 0.210 / 4.1 ≈ 0.051 (большое значение)
- Синхронизация в фазе: x₁ ≈ x₃, ẋ₁ ≈ ẋ₃
- Платформа будет колебаться с амплитудой
- Частота ≈ собственная частота платформы

### Вариант 2: Синхронизация В ПРОТИВОФАЗЕ (тяжёлая платформа)

**Метроном 1 и 2:** те же параметры, что в варианте 1

**Подвижная платформа (узел 2):**
```go
metronome2 := config.NewMovableNode(2,
    8.818,  // масса [кг] - ТЯЖЁЛАЯ платформа для синхронизации в противофазе
    0.0,    // начальное положение [м]
    0.0,    // начальная скорость [м/с]
    0.0,    // собственная жёсткость K
    0.0     // собственное демпфирование D
)
```

**Связи:** те же, что в варианте 1

**Ожидаемое поведение:**
- μ = 0.210 / 8.818 ≈ 0.024 (малое значение)
- Синхронизация в противофазе: x₁ ≈ -x₃, ẋ₁ ≈ -ẋ₃
- Платформа будет стремиться к покою (x₂ → 0)
- Частота ≈ собственная частота осцилляторов

## Дополнительные рекомендации

### 1. Начальные условия для ускорения синхронизации:

**Для синхронизации в фазе:**
```go
metronome1 := config.NewMovableNode(1, 0.210, 0.001, 0.0, 0.0, 0.0)
metronome3 := config.NewMovableNode(3, 0.210, 0.001, 0.0, 0.0, 0.0) // близкие начальные условия
```

**Для синхронизации в противофазе:**
```go
metronome1 := config.NewMovableNode(1, 0.210, 0.001, 0.0, 0.0, 0.0)
metronome3 := config.NewMovableNode(3, 0.210, -0.001, 0.0, 0.0, 0.0) // противоположные начальные условия
```

### 2. Параметры демпфирования:

Из статьи Woafo-Kraenkel следует, что демпфирование влияет на время синхронизации:
- **Меньшее демпфирование** → быстрее синхронизация, но может быть менее стабильно
- **Большее демпфирование** → медленнее синхронизация, но более стабильно

**Рекомендуемые значения:**
- Для связи метроном-платформа: d = 2.1378 Н·с/м (из статьи)
- Для связи платформа-основа: d = 3.2656 Н·с/м (из статьи)

### 3. Параметры жёсткости:

**Собственная частота осциллятора:** ω = √(κ/m)

Для m = 0.210 кг и κ = 37.108 Н/м:
- ω ≈ 13.3 рад/с ≈ 2.1 Гц

**Собственная частота платформы:**
- Для m₃ = 4.1 кг и κ₃ = 388.71 Н/м: ω₃ ≈ 9.7 рад/с ≈ 1.5 Гц
- Для m₃ = 8.818 кг и κ₃ = 388.71 Н/м: ω₃ ≈ 6.6 рад/с ≈ 1.05 Гц

### 4. Время интегрирования:

Из статьи Woafo-Kraenkel:
- Время синхронизации зависит от силы связи и начальных условий
- Рекомендуется интегрировать достаточно долго для наблюдения установившегося режима
- Для вашей системы: t₀ = 80 с, T = 120 с (40 секунд записи) должно быть достаточно

## Итоговая рекомендация

**Для начала экспериментов рекомендую:**

1. **Использовать параметры из статьи Pena-Ramirez:**
   - Массы метрономов: 0.210 кг
   - Масса платформы: 4.1 кг (для синхронизации в фазе) или 8.818 кг (для синхронизации в противофазе)
   - Жёсткости: κ = 37.108 Н/м (метроном-платформа), κ₃ = 388.71 Н/м (платформа-основа)
   - Демпфирование: β = 2.1378 Н·с/м (метроном-платформа), β₃ = 3.2656 Н·с/м (платформа-основа)

2. **Начать с синхронизации в фазе** (лёгкая платформа), так как она более наглядна

3. **Варировать массу платформы** для перехода между режимами синхронизации

4. **Мониторить разность фаз** Δ_phase между метрономами для количественной оценки синхронизации
