# Методика перебора расстройки и построения графиков

Документ описывает, как в проекте `University` считаются **разночастотность (расстройка)** и **декремент** для графиков перебора параметра `k` между лопатками.

Реализация: `scripts/sweep_detuning.py`  
Симуляция: `cmd/nsolv.go` + `internal/numMethods/utils/damping_decrement.go`

---

## 1. Постановка перебора

### Конфиг

- По умолчанию: `internal/config/confs/8blades2.json`
- Запуск с другим конфигом: `--config <имя>` (без `.json`)
- Топология: **8 подвижных лопаток** (узлы 0…7) + **фиксированный хаб** (узел 8)
- Меняются только жёсткости `k` в рёбрах **лопатка → хаб**; остальные параметры (НУ, `t`, `dt`, аэродинамика, демпфирование пружин) не трогаются

### Схема расстройки k

Старт: все `k = 1`.

Далее на шаге `δ_k` (шаг **0.005**):

| Лопатки | k |
|---------|---|
| чётные 0, 2, 4, 6 | `k = 1 − δ_k` |
| нечётные 1, 3, 5, 7 | `k = 1 + δ_k` |

Пример при `δ_k = 0.2`: `k₀ = k₂ = k₄ = k₆ = 0.8`, `k₁ = k₃ = k₅ = k₇ = 1.2`.

Перебор останавливается, когда **ε > 30%** (см. формулу ниже); точка с ε > 30% не включается.

### Пары соседних лопаток

Для графиков ε ↔ δ используются пары:

- 0–1, 2–3, 4–5, 6–7

---

## 2. Собственная частота (аналитически)

Для каждой лопатки `i` из конфига:

```
ω₀ᵢ = √(kᵢ / mᵢ)
```

В текущем конфиге `8blades2`: **mᵢ = 2** для всех лопаток 0…7.

`kᵢ` — жёсткость ребра **лопатка i → хаб 8**.

---

## 3. Процент разночастотности ε (ось X на графиках ε ↔ δ)

Для **пары соседних лопаток** (например 2 и 3) с частотами ω₁, ω₂:

```
ε = |ω₁ − ω₂| / ((ω₁ + ω₂) / 2) × 100%
```

где `ωⱼ = √(kⱼ / m)`.

На всех четырёх парах при симметричной расстройке ε **одинакова** (различаются только идентификаторы лопаток в паре).

**Пример:** `k_low = 0.8`, `k_high = 1.2`, `m = 2` → ε ≈ **20.2%**.

---

## 4. Параметр d (ось X на графике d ↔ δ̄)

Относительное СКО частот по **всем 8 лопаткам**:

```
ω₀ᵢ = √(kᵢ / m),   i = 0…7

Ave(ω₀ᵢ) = (1/8) Σᵢ ω₀ᵢ

RMSE(ω₀ᵢ) = √((1/8) Σᵢ (ω₀ᵢ − Ave)²)

d = RMSE(ω₀ᵢ) / Ave(ω₀ᵢ)
```

При одинаковых k (без расстройки): **d = 0**.

`d` — безразмерная величина; это не проценты, в отличие от ε.

## 5. Декремент δ из численного решения

### Источник данных

После каждого прогона симуляции (`CONFIG=<имя>`, `PARALLEL=false`):

- файлы `wolfram/paramsAndPoints/decrement_points<N>.txt` — локальные δ по периодам для лопатки N
- сводка в `decrement_details.log`

### Амплитуда

Для узла с равновесием `x_eq`:

```
A(t) = |x(t) − x_eq|
```

Пики амплитуды находятся по временному ряду `graph_points` / `pointsStore`.

### Локальный логарифмический декремент

По последовательности пиков `A_n` (через один период):

```
δₙ = ln(Aₙ / Aₙ₊₂)
```

Первые **2** пика пропускаются (`skipFirstMaxima = 2`) — отсекается переходный процесс.

### Декремент одной лопатки

Среднее по всем успешно посчитанным локальным δₙ для данной лопатки:

```
δᵢ = mean(δₙ)   по файлу decrement_points<i>.txt
```

(Эквивалентно `EstimateLogDecrementFromGraphPoints` в Go-коде.)

### Декремент пары лопаток (графики ε ↔ δ)

Для пары (a, b):

```
δ_pair(a,b) = (δₐ + δᵦ) / 2
```

### Средний декремент по решётке (график d ↔ δ̄)

```
δ̄ = (1/8) Σᵢ₌₀⁷ δᵢ
```

На графике `detuning_d_vs_delta_mean.png` по оси Y — **δ̄** (обозначение `$\bar{\delta}$`), не δ отдельной лопатки.

## 6. Какие графики строятся

| График | Ось X | Ось Y | Файл (диплом, конфиг 8blades2) |
|--------|-------|-------|--------------------------------|
| По парам | ε, % | δ пары | `doc/images/detuning_delta_vs_epsilon_pair_<a>_<b>.png` |
| Все пары | ε, % | δ пары | `doc/images/detuning_delta_vs_epsilon_all_pairs.png` |
| СКО частот | d | δ̄ | `doc/images/detuning_d_vs_delta_mean.png` |

На пересечении **δ = 0** (или **δ̄ = 0**) рисуется вертикальная пунктирная линия; для графиков ε ↔ δ дополнительно подписываются **ε₀** и **k** лопаток пары (интерполяция по точкам перебора).

---

## 7. Алгоритм одного прогона скрипта

1. Загрузить базовый конфиг (бэкап `*.json.bak_sweep`)
2. Для `δ_k = 0, 0.005, 0.010, …` пока ε ≤ 30%:
   - записать k в JSON конфига
   - запустить `nsolv`
   - прочитать `decrement_points0.txt` … `decrement_points7.txt`
   - посчитать ε, d, δ̄, δ по парам
3. Сохранить таблицу: `wolfram/detuning_sweep/raw_results.csv`
4. Построить PNG в `doc/images/` и `wolfram/detuning_sweep/plots/`
5. Восстановить исходный конфиг из бэкапа

---

## 8. Запуск

```bash
# Полный перебор
python3 scripts/sweep_detuning.py --config 8blades2

# Только графики из готового CSV
python3 scripts/sweep_detuning.py --config 8blades2 --plot-only
```

## 9. Типичные значения (8blades2, t=100)

| Режим | ε | d | δ̄ |
|-------|---|---|-----|
| Все k = 1 | 0% | 0 | ≈ −0.133 (рост амплитуды) |
| δ̄ = 0 | — | ≈ 0.0402 | 0 |
| k = 0.8 / 1.2 | ≈ 20.2% | — | ≈ +0.11 (затухание) |

---

## 10. Ограничения

- Скрипт рассчитан на **8 лопаток + хаб id=8** и массу m=2
- ε и d считаются **аналитически** из k, m конфига
- δ и δ̄ — из **численного** интегрирования аэроупругой модели
- Для нового конфига с другим числом лопаток или топологией скрипт нужно адаптировать
