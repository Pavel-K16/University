## 1. О чём работа (одним абзацем)

**Бакалаврская ВКР:** аэроупругие колебания **лопаточной решётки авиационного двигателя** в упрощённой **дискретной** модели (кольцо связанных осцилляторов на графе + линеаризованная аэросвязь с соседями).

**Цель:** разработать программный комплекс для параметрического анализа, интегрировать уравнения движения во времени, **исследовать** затухание/рост амплитуды, декремент, частоту, межлопаточную фазу — **без** полномасштабного CFD на каждом варианте.

**Не в scope:** явное гармоническое вынуждение потоком \(F\cos\omega t\) (вынужденные колебания упоминаются во введении только для контраста с флаттером).

---

## 2. Физика и термины

| Термин | В работе |
|--------|----------|
| **Флаттер** | Неустойчивый рост амплитуды из‑за аэроупругого взаимодействия с потоком (не резонанс на внешней частоте). |
| **Вынужденные колебания** | Реакция на периодические возмущения потока; **в модели не задаются** явно. |
| **Свободные колебания** | Заданы \(x_i(0), v_i(0)\), дальше интегрирование; смотрим затухание или рост. |
| **Однородная решётка** | Все лопатки одинаковые по \(m, k, d\) к хабу, симметричные НУ (напр. шаг фазы 135°). |
| **Неоднородная решётка** | Разные \(k_{i}, d_{i}\) к хабу (и при необходимости др. параметры) при той же топологии кольца. |
| **Дискретная модель** | Конечное число степеней свободы \(x_i(t)\), не УЧП по оболочке лопатки. |

**Актуальность (для текста):** ПД-8 и др.; CFD дорогой; нужен быстрый перебор конструктивных и аэродинамических параметров решётки.

## 3. Постановка задачи (математика)

### 3.1. Система

- \(p\) **подвижных** узлов — лопатки, одна координата \(x_i(t)\) на лопатку (смещение относительно равновесия).
- Один **фиксированный** узел — хаб (id обычно 8 в конфигах на 8 лопаток).
- **Граф:** рёбра = пружины (\(k_{ij}\)), демпферы (\(d_{ij}\)), `rest`; кольцо замыкается **periodic**-ребром между первой и последней лопаткой.
- **Аэро** (если `aero.enabled`): силы от соседних подвижных лопаток с коэффициентами **`ForwardAeroKoef`** \(f\) и **`BackAeroKoef`** \(b\), масштаб \(\frac{1}{2}\rho V^2 b_{\text{хорды}} \cdot \text{Scale}\).

### 3.2. Уравнение

Для подвижной лопатки \(i\) с массой \(m_i\):

\[
m_i \ddot{x}_i = F_i^{\text{упр}}(\mathbf{x}, \dot{\mathbf{x}}) + F_i^{\text{aero}}(\mathbf{x}),
\]

где \(F^{\text{упр}}\) собирается в `graph.NetForce` по рёбрам, \(F^{\text{aero}}\) — в `graph.GetAeroForce`.

### 3.3. Численное решение

- Интегратор: **РК4**, `internal/equationSolver/graphSolver.go`, шаг `dt` из JSON.
- Интервал: \(t \in [t_0, T]\) из `times` в конфиге.
- Конфиг: `CONFIG=<имя>` → `internal/config/confs/<имя>.json` (запуск из `scripts/`).

### 3.4. Однородная vs неоднородная (примеры конфигов)

| Тип | Файл | Признак |
|-----|------|---------|
| Однородная | `8usual.json` | К хабу у всех лопаток одинаковые `k=1`, `d=0`; НУ с равномерным фазовым шагом 135°. |
| Неоднородная | `8blades2.json` | Разные `k`, `d` на рёбрах лопатка→хаб (напр. `k=1.07`, `d=0.04` не у всех). |

Топология: 8 лопаток `0…7` + хаб `8`, цепочка по кольцу + periodic `0↔7`.

## 4. Что вычисляется после прогона (постобработка)

| Величина | Как | Код / файлы |
|----------|-----|-------------|
| Траектории \(x_i(t)\) | Интегрирование | `graph_points*.txt`, `PointsStore` |
| **Логарифмический декремент** \(\delta\) | По пикам амплитуды \(\|x-x_{eq}\|\): \(\delta_k=\ln(A_k/A_{k+2})\), усреднение; `skipFirstMaxima` | `damping_decrement.go`, `decrement_points*.txt` |
| **Частота** \(f\) [Гц] | \(1/(t_{k+2}-t_k)\) между пиками | `frequencyStore`, лог `LogFrequencySummary` |
| **Межлопаточная \(\Delta\varphi\)** | \(\varphi(\text{сосед})-\varphi(\text{узел})\), variant A (Самойлович): \(\psi=\atan2(-(v+\delta_r a), \nu a)\), локальный ZOH \(\delta(t), f(t)\); unwrap как в Python | `phase_diff.go`, `interblade_phase_points*.txt` |
| **Абсолютная фаза** \(\varphi_i(t)\) | Та же формула для одной лопатки | `blade_phase_points*.txt` |
| **Устойчивость** | Затухание vs рост амплитуды, знак/величина \(\delta\) | По графикам амплитуды и декремента |
| **Параметрические карты** | Сетка \((f,b)\) при `PARALLEL=true` | `decrementStore`, `freqStore`, `phaseDiffStore` → JSON + `plot_points.py` |

**Env:** `SKIP_FIRST_MAXIMA` (default 2) — сколько первых пиков **не** учитывать в **среднем** декременте для отчётов; для фазы пики берутся с `FindAmplitudeMaximaForPhase` (без ложного пика в \(t=0\)).

**Важно по фазе (фиксы 2025):**

- Пики для фазы: `FindAmplitudeMaximaForPhase` (без «левого края» в \(t_0\)).
- Пара лопаток: синхронный ZOH `min(k_A,k_B)`, **без** усреднения \(\delta\) между соседями (у каждой свой \(\delta\) в окне).
- `holdPair` — держать \(\delta[0]\) до созревания пиков у обеих лопаток пары.

## 5. Режимы запуска

```bash
cd scripts
export CONFIG=8usual          # или 8blades2, 8blades, …
export PARALLEL=false         # один прогон + txt для графиков
export SKIP_FIRST_MAXIMA=2    # опционально
./run.sh                      # go build + nsolv
python3 ../plots/plot_points.py
```

| `PARALLEL` | Поведение |
|------------|-----------|
| `false` | Один \((f,b)\) в коде (`cmd/nsolv.go`), пишет `graph_points*`, `interblade_phase_points*`, декремент в консоль. |
| `true` | Перебор \(f,b \in [-1,1]\) шаг 0.1, горутины, stores → JSON, карты в `plots/`. |

Коэффициенты \(f,b\) в single-run задаются в `solveWithGraph` (см. актуальные значения в `cmd/nsolv.go`).

## 7. Аэромодель (кратко, для сверки с 10.83)

- В цикле по соседям: вклад \(\propto f\) или \(b\) × \((x_{\text{сосед}} - x_{\text{eq,сосед}})\) (скорость соседа в аэро **закомментирована** в типичной конфигурации).
- Self-ребро в `NetForce` / `GetAeroForce` пропускается.
- Равновесие лопатки к хабу: `equilibriumForNodeFromConfig` — `x_eq = x_hub - rest` (или `+ rest` для ребра hub→blade).

Подробнее: `doc/3Blades_force_check.md`, `doc/graphUsage.md`.

## 9. Типичные вопросы другого чата

**Q: Почему модель «дискретная»?**  
A: Конечное число \(x_i(t)\), не поле по лопатке/каналу.

**Q: Чем однородная отличается от неоднородной?**  
A: Одинаковые vs разные механические параметры крепления лопаток к хабу (и возможно НУ); аэрокоэффициенты \(f,b\) могут перебирааться одинаково в обоих случаях.

**Q: Заменяет ли это CFD?**  
A: Нет. Предварительный перебор и оценка тенденций устойчивости.

**Q: Откуда −135°?**  
A: Равномерная решётка с фазовым шагом 135° между соседями в НУ (`8usual`); при корректной постобработке фазы \(\Delta\varphi\approx -135^\circ\).

## 10. История правок (кратко, если чат лезет в фазу)

- Unwrap \(\Delta\varphi\) по разности, не по отдельным \(\varphi_i\).
- Локальный ZOH \(\delta(t), f(t)\) вместо одного среднего δ на весь прогон.
- Убран ложный пик в \(t=0\) для фазы (`FindAmplitudeMaximaForPhase`).
- Синхронный индекс ZOH для пары лопаток; усреднение δ между соседями **снято** по запросу пользователя.
