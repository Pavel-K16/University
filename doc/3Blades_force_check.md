# Сверка сил для конфига 3Blades (3 лопатки в кольце)

Конфиг: `internal/config/confs/3Blades.json`  
Кольцо: узел 0 — соседи 1 и 2; узел 1 — соседи 2 и 0; узел 2 — соседи 0 и 1.  
Параметры: k=1, d=0.1 для всех рёбер; масса 1; аэро: ρ=V=b=1, **scale=1.0**.

## Начальное состояние (t=0)

- x0 = 1, v0 = 0  
- x1 = 2, v1 = 0  
- x2 = 3, v2 = 0  

## Механические силы (пружина + демпфер)

Формула для узла i от ребра (i, j): **−k·(xi − xj − rest) − d·(vi − vj)**.

**Узел 0** (рёбра к 1 и к 2):

- От (0,1): dx = 1−2 = −1, dv = 0 ⇒ −k·(−1) − d·0 = **+1**
- От (0,2): dx = 1−3 = −2, dv = 0 ⇒ −k·(−2) = **+2**
- **F0_mech = +1 + 2 = 3**

**Узел 1** (рёбра к 2 и к 0):

- От (1,2): dx = 2−3 = −1 ⇒ **+1**
- От (1,0): dx = 2−1 = 1 ⇒ −k·1 = **−1**
- **F1_mech = 1 − 1 = 0**

**Узел 2** (рёбра к 0 и к 1):

- От (2,0): dx = 3−1 = 2 ⇒ −k·2 = **−2**
- От (2,1): dx = 3−2 = 1 ⇒ −k·1 = **−1**
- **F2_mech = −2 − 1 = −3**

## Аэродинамические силы

Формула: **F_n = Scale · (1/2)·ρ·V²·b · (y_next − y_prev)** (соседи в кольце: next = n+1, prev = n−1 по модулю 3).

Коэффициент: Scale · 0.5·1·1·1 = **1.0 · 0.5 = 0.5**.

- **Узел 0:** next=1, prev=2 ⇒ F0_aero = 0.5 · (x1 − x2) = 0.5·(2−3) = **−0.5**
- **Узел 1:** next=2, prev=0 ⇒ F1_aero = 0.5 · (x2 − x0) = 0.5·(3−1) = **+1**
- **Узел 2:** next=0, prev=1 ⇒ F2_aero = 0.5 · (x0 − x1) = 0.5·(1−2) = **−0.5**

## Полная сила на узел (что должно быть в коде при t=0)

| Узел | F_mech | F_aero | F_total |
|------|--------|--------|---------|
| 0    | 3      | −0.5   | **2.5**   |
| 1    | 0      | +1     | **1**     |
| 2    | −3     | −0.5   | **−3.5**  |

## Как сверять с кодом

1. Запустить с конфигом `CONFIG=3Blades` и в начале первого шага (до `solver.Step`) вывести для каждого узла `graph.NetForce(0)`, `NetForce(1)`, `NetForce(2)`.
2. Сравнить с таблицей выше: при совпадении начальных условий и формул значения должны совпадать с точностью до округления.

Если F_mech в коде не совпадает — проверять знаки и учёт рёбер в цикле по `node.Edges`. Если F_aero не совпадает — проверять `GetInfluenceKoefs` (кто next/prev для каждого узла) и формулу в `GetAeroForce`.

## Аналитическое решение (сравнение с численным)

Система **линейная** (постоянные коэффициенты k, d и линейная аэро), поэтому у неё есть аналитическое решение в виде комбинации экспонент и, при наличии затухания, затухающих колебаний.

**Аэро в уравнении:** F_aero,n = **c** · (**(+1)·y_next + (−1)·y_prev**). Величина **c** — это общий множитель перед суммой из статьи: **c = Scale · (1/2)·ρ·V²·b**; при Scale=1, ρ=V=b=1 получается **c = 0.5**. Коэффициенты **+1** и **−1** как раз дают разность: (+1)·y_next + (−1)·y_prev = **y_next − y_prev**, поэтому в коде ниже аэро-слагаемое записано как `c*(x_next - x_prev)` для каждого узла (для 0: x1−x2, для 1: x2−x0, для 2: x0−x1).

В Wolfram Mathematica:

```mathematica
k = 1; d = 0.1; c = 0.5;   (* c = Scale * 0.5*ρ*V²*b *)
eq0 = x0''[t] + (2*k*x0[t] - k*x1[t] - k*x2[t]) + d*(2*x0'[t] - x1'[t] - x2'[t]) - c*(x1[t] - x2[t]) == 0;   (* аэро: c * ((+1)*x1 + (-1)*x2) *)
eq1 = x1''[t] + (2*k*x1[t] - k*x2[t] - k*x0[t]) + d*(2*x1'[t] - x2'[t] - x0'[t]) - c*(x2[t] - x0[t]) == 0;   (* аэро: c * ((+1)*x2 + (-1)*x0) *)
eq2 = x2''[t] + (2*k*x2[t] - k*x0[t] - k*x1[t]) + d*(2*x2'[t] - x0'[t] - x1'[t]) - c*(x0[t] - x1[t]) == 0;   (* аэро: c * ((+1)*x0 + (-1)*x1) *)
ics = {x0[0]==1, x0'[0]==0, x1[0]==2, x1'[0]==0, x2[0]==3, x2'[0]==0};
analitSol = DSolveValue[{eq0, eq1, eq2, ics}, {x0[t], x1[t], x2[t]}, t];
```

Дальше: построить график `analitSol` и наложить на него точки из `graph_points1.txt`, `graph_points2.txt`, `graph_points3.txt` (численное решение). При малом шаге dt численное и аналитическое должны совпадать с точностью порядка метода (РК4).

Если DSolve даёт слишком громоздкое выражение, можно считать аналитическое решение в отдельных точках через `analitSol /. t -> 0.1` и т.д. и сравнить с численными значениями из файлов.
